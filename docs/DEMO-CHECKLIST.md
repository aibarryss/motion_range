# Чек-лист демо и защиты (готовить в Ср, до 13:00)

## Слайды (6–8 экранов)

- [ ] Титул: название, команда, направление A / GAME
- [ ] Проблема одним предложением: «Управление — это барьер. Мы убрали его: камера вместо джойстика»
- [ ] (вместо слайда) живое демо
- [ ] Твист: 5 жестов схемой
- [ ] Режим «ошибка»: скриншоты подсказок с числами
- [ ] Техническая схема: поток данных от камеры до игры
- [ ] Что дальше
- [ ] Спасибо + ссылки (репо, деплой)

## Обязательная страховка

- [ ] **Запись экрана 60 с** — идеальный прогон раунда (страховка, если у жюри не заведётся камера/свет)
- [ ] Скриншот-набор из 5 картинок: главный экран, калибровка, всплывшая подсказка ошибки, финал со счётом, README на GitHub
- [ ] Запись и скриншоты — в репозиторий (папка `demo/`), не только на чьём-то ноутбуке

## Репетиция (Ср 13:00–14:00)

- [ ] Прогон питча вслух ×2 (по таймеру, 3 минуты)
- [ ] Ответы на 6 вопросов жюри отрепетированы (docs/PITCH.md)
- [ ] Запасной план проговорён: камера/свет/деплой подводят → «показываю запись»

## Перед выходом к жюри

- [ ] Свет включён, фон ровный, ноутбук на зарядке, вкладка открыта заранее, разрешение на камеру выдано
- [ ] Вкладка с записью 60 с открыта в соседней вкладке
- [ ] Облегчённый режим включён, если машина чужая/слабая
