# Режим «ошибка»: измеримая диагностика

> Ядро проекта (20 из 100 баллов). Владелец: A. Техническая спецификация: [SPEC_Diagnostics_and_Fire.md](SPEC_Diagnostics_and_Fire.md).

## Главные правила

1. Подсказка называет **измеренное значение и порог**, а не «движение не распознано».
2. Каждый код — одно правило, одна метрика, одна подсказка, одна подсветка на скелете.
3. Различаем **ошибку игрока** (жест выполнен неверно: THUMB_OUT, SHOOT_TOO_SLOW, PALM_ROLL, PALM_EDGE → «сделай иначе») и **ошибку среды** (жест верный, распознаванию мешает обстановка: TOO_DARK, LOW_CONFIDENCE, SLOW_FPS → «проблема не в тебе, поправь вокруг»).

## Формат полного ответа (4 части)

1. **Что произошло** → «Щит не активирован»
2. **Почему** → «Ладонь повёрнута ребром: palmFrontality 0.34, нужно > 0.7»
3. **Что сделать** → «Поверни ладонь к экрану»
4. **Как понять, что исправил** → шкала 34% → 78% + зелёная подсветка

| `HAND_OFFSCREEN` | позиции точек | ≥3 из 21 точки вне центральных 90% кадра | «Рука вышла из кадра — верни её в центр» | вышедшие точки |

| `SLOW_FPS` | fps | < 18 | «Включаю облегчённый режим: тормозит устройство» | — (системная) |

## Панель «Signal Doctor»

Боковая панель из 4 индикаторов: `Hand visible` · `Palm facing camera` · `Fingers open` · `Motion speed`. При ошибке подсвечивается **ровно один** проблемный индикатор + соответствующие landmark-точки на оверлее, рядом — измеренное значение и порог.

## Адаптивная калибровка (15 с перед раундом)

Игрок показывает открытые ладони → сжимает кулак → тестовый release → наклоны. Сохраняется персональный baseline (стабильный размер кисти, личный темп раскрытия, норма большого пальца в кулаке). Подсказки сравнивают текущее значение с **личной нормой**, а не универсальным текстом: «Ты раскрываешь за 700 мс, твой обычный темп 380 мс — раскрывай резче».
