# MOTION RANGE

**Self-correcting gesture shooter** — браузерный тир, в котором веб-камера работает вместо джойстика. Игра не просто реагирует на жесты: она измеряет физические признаки распознавания и при сбое объясняет игроку конкретную причину — с числами и порогами — и в реальном времени учит выполнять жесты так, чтобы камера их понимала.

Хакатон «Admit» · Кейс «Motion. Камера вместо джойстика» · Направление **A / GAME**

> Репозиторий в активной разработке: хакатон идёт 28–30 сентября 2026, финальная версия — к 30.09 15:00 (UTC+5).

## Жесты

| Жест | Действие |
|---|---|
| ☝️ Указательный палец | Прицел следует за кончиком пальца |
| ✊→🖐 Резкое раскрытие кулака (< 400 мс) | Выстрел — динамический жест, собственная логика команды |
| 🖐 Ладонь плоско к камере | Щит |
| Наклон корпуса влево/вправо | Уклонение от снаряда |
| 🤏 Пинч | Заморозка времени (бонусный) |

Подробности реализации твиста: [docs/TWIST.md](docs/TWIST.md). Режим «ошибка»: [docs/ERROR-MODE.md](docs/ERROR-MODE.md).

## Запуск

Требования: **Node.js ≥ 20**, браузер **Chrome или Edge**, веб-камера, ровное освещение перед лицом.

```bash
git clone https://github.com/aibarryss/motion_range.git
cd motion_range
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`), и разрешите доступ к камере.

Production-сборка: `npm run build && npm run preview`.

## Troubleshooting

- **Камера не включается** — разрешите доступ к камере для сайта; приложение требует HTTPS или `localhost`; проверьте, что камеру не заняла другая вкладка или приложение.
- **Жесты не распознаются** — встаньте в 60–80 см от камеры, источник света перед лицом, а не за спиной. Игра сама подскажет, что именно не так: см. [docs/ERROR-MODE.md](docs/ERROR-MODE.md).
- **Низкий FPS** — включите облегчённый режим (отключает трекинг позы и снижает разрешение видео).
